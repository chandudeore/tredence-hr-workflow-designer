# HR Workflow Designer

A modern React + React Flow application for designing and testing HR workflows with a drag-and-drop interface.

## Features

### ✅ Core Features

1. **Visual Workflow Designer**

   - Drag-and-drop nodes from sidebar
   - 5 custom node types: Start, Task, Approval, Automated, End
   - Connect nodes with edges
   - Canvas controls (zoom, pan, minimap)

2. **Node Configuration**

   - Dynamic forms for each node type
   - Real-time validation
   - Type-safe data handling
   - Custom fields support

3. **Workflow Testing**

   - Step-by-step simulation
   - Execution log with status tracking
   - Workflow validation
   - Export/Import JSON

4. **Mock API Integration**
   - Simulated backend responses
   - Configurable automated actions
   - Realistic async operations

### 🎨 UI Features

- Modern, clean interface matching provided design
- Metric dashboard
- Responsive layout
- Dark/light mode ready
- Professional color scheme
